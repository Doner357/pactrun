# User guides

Use this section to operate Packs supplied by authors you trust. The first four
pages form an onboarding route; the later task and reference pages are choices,
not a sequence of commands to execute against one Instance.

## Start here

1. [Install and verify Pactrun](./installation.md). If a verified command is
   already available, you can skip extraction and check its version/path.
2. [Create your first Instance](../introduction.md) in an isolated store. This
   empty-Pack exercise teaches the command flow and cleans up its example.
3. [Install a supplied Pack and create a usable Instance](./use-pack.md).
   Follow its actual capabilities rather than assuming the empty example is a service.

You are ready to choose an operating task when you know the selected store,
Instance name, active Revision, and the capability you intend to use. To choose
a persistent or separate environment, read [data locations](./data-location.md).
