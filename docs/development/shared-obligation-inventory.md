## Classification and acceptance

- **Cited**: owning text cites concrete test IDs; this is linkage, not a new claim
  that every user-visible result is proved. E/S3 revalidates the formal baseline.
- **Audit**: Pending/partial/uncited coverage remains unresolved. The assigned owner
  must identify actual evidence or implementation work; no placeholder IDs or bulk
  conversion to Passed is permitted. Each row retains its exact owning contract.
- **A acceptance**: A's rows require the new live/history/Instance acceptance, not
  mere parser or repository methods. Other rows do not expand A's runtime scope.
- **Exclusion check**: conditional isolation promises do not authorize new sandboxing.
